a cli for odin monorepos

One repo,
every app in it.

loki scaffolds apps, wires up shared packages, and pins third-party code as git submodules — so an Odin monorepo stays one odin build away from working, no matter how many pieces it has.

Three directories, one tool

loki doesn't invent a new project shape — it just knows the one Odin monorepos already tend to have, and automates the parts that get tedious by hand.

apps/

Every binary in the repo, scaffolded the same way. loki build compiles one app or all of them, each to its own bin/ output.

packages/local/

First-party code shared across apps. loki discovers leaf packages by walking the tree — no manifest entry to keep in sync by hand.

packages/vendor/

Third-party dependencies, pinned as git submodules. loki doctor catches uninitialized or drifted vendor code before it breaks a build.

Commands

The full surface area. Run loki help any time for this from the terminal.

loki new <name>Scaffold a new monorepo project
loki new app <name>Scaffold a new app in the current project
loki new pkg <name>Scaffold a new local package in the current project
loki add <git-url> [name]Add a third-party package as a git submodule
loki syncInit/update all vendor submodules
loki run <app> [-- args]Run an app
loki build [app]Build an app, or every app if omitted
loki test [target]Test a package, or every local package if omitted
loki doctorCheck that the environment is set up correctly

Install

Needs the Odin compiler (dev-2026-07 or newer) on your PATH. Build loki from source:

$ git clone https://github.com/a-man-called-q/loki.git
$ cd loki
$ ./build.sh

Drop the resulting bin/loki on your PATH, then run loki doctor to confirm the environment checks out.
